# Municipal Attendance Frontend

Frontend application for the Municipal Attendance & Task Management System.

## Technology Stack

* Next.js
* TypeScript
* TailwindCSS
* Axios

## Design Goals

* Mobile-first
* Clean government-grade UI
* Fast and responsive
* Minimal learning curve
* Future-ready for mobile app conversion

## Planned Screens

### Authentication

* Admin Login
* Employee Login

### Admin

* Dashboard
* Employees
* Offices
* Attendance
* Tasks
* Reports
* Audit Logs
* Error Logs

### Employee

* Dashboard
* Mark Attendance
* My Tasks
* Task History
* Attendance History
* Profile

## Development

Start development server:

```bash
npm run dev
```

Application runs at:

```text
http://localhost:3000
```

Backend API:

```text
http://localhost:8000
```
